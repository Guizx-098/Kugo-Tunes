## SPD Turbo 2.1.0

**Download:** `SPD-Turbo.apk` (below, under *Assets*). Open it on your Android phone to install.

### What's new
- Language option (English / Português do Brasil) in Preferences
- In-app updates: "Check for updates" button, update dialog, APK download with progress and install
- Smoother and faster interface
- Fixes and improvements for YouTube / YouTube Music downloads

> First time coming from an older build? Uninstall the old version once: this release uses a fixed signing key so future updates install over it normally.

### Novidades (pt-BR)
- Opção de idioma (English / Português do Brasil) em Preferências
- Atualização dentro do app: botão "Checar atualizações", aviso de nova versão, download do APK com progresso e instalação
- Interface mais fluida e rápida
- Correções e melhorias nos downloads do YouTube / YouTube Music

> Vindo de uma versão antiga? Desinstale a antiga uma vez: esta versão usa uma chave de assinatura fixa, então as próximas atualizações instalam por cima normalmente.
